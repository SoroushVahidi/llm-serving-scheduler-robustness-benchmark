# Preliminary future physical fidelity gates

**DRAFT; all future physical gates NOT VERIFIED.** A PASS is per approved contract/profile/model/deployment/case, not general scheduler support. FAIL is observed contradiction; NOT VERIFIED is absent/inadequate observation. Neither startup, job exit, a saved PASS flag nor CPU checks can establish serving fidelity. Negative fixtures PASS only as successful rejection tests, never as inference success.

| Gate (protocol mapping) | Required evidence and PASS rule | FAIL / NOT VERIFIED action |
|---|---|---|
| G0 approval/identity (F0,F1) | Author-approved specification/corpus/profile SHA; clean exact execution checkout, model/tokenizer/source/config/trace hashes, capacity and hardware identity; frozen scope and resource authorization | Do not allocate or execute unsupported configuration. The known historical LFS filter discrepancy must be explained/resolved for an execution checkout without altering history. |
| G1 metadata/arrival (F4,F7) | Exactly one offered->dispatch->ingress->route->engine binding, exact class/SLO/strict flag/ordinal, preserved open-loop arrivals and input IDs | Stop on duplicate/missing IDs, hidden backpressure, truncation or unjustified filtering. Retain every offered outcome. |
| G2 independent decisions (F1,F2) | Frozen hand cases plus independent reference produce exact admitted/held/preempted/position/token maps; every mechanism has distinguishing cases | Zero required-case mismatches; do not weaken oracle expectations to accommodate native fallback. |
| G3 actual execution (F3) | Final plan equals native acceptance and all required runner executed spans/epochs; proper zero/intermediate and first/final sample masks | Optimistic counters alone -> NOT VERIFIED. Unexpected samples/spans/rank ACKs -> FAIL. |
| G4 KV conservation (F5) | Per-group/rank allocated/free/null/reserved/pinned counts reconcile; actual victims and block reuse/free match approved policy and causal fences | Abort on unexplained refusal, victim, double-free, stale KV read or nonfinite/impossible telemetry. GPU-memory fraction cannot substitute for block evidence. |
| G5 recomputation/output (F3,F5,F7) | Prefix survives repeated preemptions; original P/O and first-token history immutable; replay tokens counted separately; exactly one emission of each new token | Any output rollback/re-emission/limit reset or hidden retry -> FAIL. Cancellation and late ACK must be explicitly exercised. |
| G6 policy timing (F4) | Recorded host batch boundary, independent mean/LST reconstruction, declared occupancy denominator/offset; no hold/partial/terminal refresh | Source software similarity alone is insufficient. Wrong clock domain or unsupported timing feedback -> FAIL/NOT VERIFIED. |
| G7 metrics/observability (F4,F7) | Correct arrival/dispatch/admission/first observation/completion; endpoint-specific metrics; token-index evidence for every required token gap | Coalesced chunks or missing emissions -> token-gap metric NOT VERIFIED; preserve unknown classification and no implicit denominator exclusion. |
| G8 errors/drain (F7,F9) | Explicit invalid/rejected/failed/cancelled/timed-out/incomplete accounting, bounded startup/drain, cleanup and durable evidence for every request | Never call missing responses successful or retry with another allocation automatically. |
| G9 overhead (F8) | Independently authorized paired instrumentation comparison against a frozen overhead criterion (protocol's ≤2% proposal still needs approval) | If overhead is excessive/unmeasured, no primary-performance eligibility; use a separately labeled profiled stratum only after approval. |
| G10 TP2 (F6) | Required ranks agree on request/epoch/token positions, sampling owner and collective completion; capacity reconciles per rank, no duplicate output | Missing-rank progress is NOT VERIFIED; rank disagreement/duplicate commit is FAIL. TP1 passes do not lift this gate. |
| G11 DP2 (F6) | Predetermined routes, exactly-once receipt/completion, router vs replica queues, per-replica LST/KV/timing and fixed failure handling | Two ready servers are not DP validation; silent reroute/work stealing/retry is FAIL. |
| G12 reproducibility/deployment (F0,F9) | Durable raw journals, hashes/checkpoints, exact commands/dependencies and topology; repeated approved cases preserve decision/output-accounting invariants | New GPU architecture, model, kernel, source, contract or topology requires its own gate. Numeric output equality is descriptive unless separately required. |

Recommended physical case order, **only after later authorization**: short/long/partial TP1; mixed decode/paused-prefill/new admission and class ties; deliberate temporary KV refusal; preemption/recompute/output-prefix and cancellation; then overhead/repeatability. Native and adapted-SLAI receive identical approved inputs/controls but are not expected to produce identical policy decisions or numerical text. TP2 and DP2 are separate later gates. Every failure retains evidence and stops the authorized scope; no automatic second allocation.

No GPU time, wall limit, pressure value or future workload is approved here. MGPU06's still-unexecuted bounded pair would only assess its existing instrumentation contract; it cannot satisfy these new long-prompt/KV/distributed cases.
