This does not edit or approve the frozen protocol's [A01–A16 register](../../study-protocol/lssp-protocol01/AUTHOR_DECISIONS.md). Original provisional recommendations remain historically recorded. Every recommendation below requires author review; source inspection and CPU checks do not constitute approval.
