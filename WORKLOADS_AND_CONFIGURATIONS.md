# Workloads, transformations and execution contract

The three workload sources are Azure LLM Inference Trace 2024, Bailian/Qwen To-B, and BurstGPT v2.0. Exact acquisition links, upstream commits, expected byte sizes, SHA-256 values, attribution and license texts are in `PROVENANCE_AND_RIGHTS.md`. Download originals directly from their providers if reconstructing selection. A Git LFS pointer is not the Bailian trace. The original trace files are intentionally absent.

The frozen 120-window corpus contains 40 windows per source, each with 200 requests. Selection and filtering preserve valid source-row indices, numeric token lengths, source file hashes and chronological/overlap diagnostics. Arrival times are rebased; priorities are uniform; seeded synthetic deadlines and output predictions are generated in the metric/input layer. Six inherited arrival/deadline compression settings preserve their original window-specific load factors. Those settings do not equate absolute load across sources. Source windows and conditions are reused design inputs from LSSP, not newly sampled independent observations. Bailian block-size metadata must not multiply token lengths.

`evidence/input-lineage/windows.json` holds the frozen windows. `evidence/c01/inputs/full-inputs.json` holds 720 exact request conditions. `evidence/c01/research/lssp-c01-full/input_manifest.json` binds window/condition hashes, source overlap, configurations, seeds, factors and policies. `tables/c01-conditions.csv` exposes all 720 synthesis seeds and condition hashes without request records. STAT01 seeds and scenario definitions remain in `evidence/stat/code/` and the original/recovery launch and source-batch records; no new seed schedule is substituted.

For reconstruction from acquired upstream inputs, inspect the source adapters in `code/c01/src/robustbench/`, the frozen window/calibration manifests in `code/c01/`, and `code/c01/research/lssp-c01/{prepare.py,PROTOCOL.md}` plus `code/c01/research/lssp-c01-full/{prepare_full.py,PROTOCOL.md}`. Source locations are recorded in the inventory. The saved selection, exact row indices and hashes are the authority. Historical launch commands contain cluster paths; copying those paths verbatim is not a portable workflow. Selection reconstruction and full campaign execution were not rerun or certified as turnkey here.

CM-0.1 is a CPU discrete-event model of one abstract device. Each positive batch takes 0.001 simulated seconds, independent of composition. Budget B=32,768 work tokens; prefill token cost=1; each selected decode request produces one token for cost=1. Context reservation is 32,768 tokens per resident, with total KV capacities 131,072 or 262,144 (four or eight effective resident slots). Allocator block=16 tokens, maximum sequence setting=64, and administrative drain horizon=50 seconds after the last arrival. Full-context reservations, not the nominal sequence setting, bind residency. No eviction, preemption, migration, prefix sharing or recomputation occurs. A completed prefill emits no output until a subsequent decode batch. Policies observe arrived inputs and progress, not latent output lengths, future arrivals or output-derived deadlines.

| Policy identifier | Rule |
|---|---|
| whole_fcfs_c01 | Whole-prompt FCFS prefill admission takes priority over decoding when admission is possible. |
| chunked_fcfs_c01 | Residents before waiting work in stable arrival order; at most 512 prefill tokens per request per batch. |
| decode_first_c01 | Resident decodes, then resident prefills, then waiting prefills; 512-token prefill cap. |
| slo_gated_c01 | Critical resident decodes, paused prefills, shortest waiting prompts, then residual decodes; 0.495-second critical-age threshold. |

The authoritative launch-pinned implementation is `evidence/c01/research/lssp-c01/{engine,policies,validator}.py`, with source hashes in launch.json. `code/c01` and `code/stat01` preserve distinct execution revisions; the manuscript revision must not replace those execution identities. See `COMMITS.json`.

The budget study uses six preselected conditions, eight slots, budgets 32,768/2,048/1,024, and four policies. Its 72 rows include baseline-budget controls; do not count them as 72 independent windows. Its manifest records the actual run identity and source matches. BOUND01 establishes equivalence for the named fixed policies starting empty under its assumptions, including admissible prompt lengths. The theorem is not extended to policy switching, altered resource semantics, SLO-gated, or physical timing.

Original C01 execution used Wulver, one CPU, no GPU, 4 GiB requested memory, Python 3.12.13, Linux 5.14/glibc 2.34. CPU model is not pinned by the archived environment record. STAT01 records Python 3.12.13, NumPy 2.5.2 and SciPy 1.18.1; budget execution records Python 3.12.3. Exact environment/resource records remain with each launch. The verification environment is separately documented in ENVIRONMENT.json and the dependency freeze. This audit reused that previously clean Python environment on the same Linux host, not a second machine or fresh OS/container.


## Reviewed extensions in rc3

TIME01 and ABL01 are included after independent scientific review and author-authorized integration. TIME01 contains 384 new variable-duration executions and 384 reused fixed baselines across 24 purposively selected windows, two settings, two capacities and four adaptations. ABL01 has 1,440 paired original/derived controls and zero new simulations; its frozen simulated:false identities are preserved. These dependent views are not additional independent experiments. TIME01 is synthetic, not hardware-calibrated; selected BurstGPT mean latency is worse under both clocks. ABL01 isolates the prompt-ordering trade-off within the original nonbinding contract; it does not establish universal optimality. Historical frozen scientific_review_required:true flags remain unchanged and are superseded by the dated hash-linked independent review verdict, not silently edited.

No additional raw provider traces are distributed. The immutable manifests retain historical operational filesystem paths as provenance, not access credentials. Frozen execution code and review scripts retain their original bytes; tools/reproduce_extensions.py maps dependencies to package-relative locations in an external writable directory. Anonymous transformed Bailian session/cache fields remain linkable to public upstream records; they are omitted from the table mirrors.
