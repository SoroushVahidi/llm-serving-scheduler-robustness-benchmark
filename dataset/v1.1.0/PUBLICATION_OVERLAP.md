# Prior publication and exact overlap

This release is a fuller publication of the same completed LSSP campaign, not new experimentation. The existing [Hugging Face LSSP v1.0.0 dataset](https://huggingface.co/datasets/SoroushVahidi/llm-serving-scheduler-portability) includes selected RQ1/RQ2 and RQ4 tables plus a separate RQ6 result, but not this final complete matrix or the six exact canonical analysis files.

The [GitHub engineering-smoke artifact](https://github.com/SoroushVahidi/llm-serving-scheduler-robustness-benchmark/blob/099ee18955b5007f8a92f657067c3e14d31d7ec7/artifacts/manifests/ranking_portability_phase12_smoke_raw.json) contains 468 unique execution keys. Comparison keyed on cell_id and required matching source family, window, policy, region, repetition, synthesis seed, load factor, eleven numerical metrics and telemetry. JSON numbers were parsed as exact decimals with equal NaN treated as the same undefined state; no tolerance or rounding was used. The 468-row normalized result-projection SHA-256 on each side is c46dc974064d375b9d19b0863cedc5a9fd86afda85344928f21aee180e2f7efb. The original smoke file SHA-256 is 3b4b5602b5080c6ff647b9301ee275867060fd283d140885afd47ca5fe49bdfd.

The shared keys are 468/18,720 (2.5%), covering 234/9,360 configurations. The other 18,252 keyed outcomes, across 9,126 configurations, had no numerical counterpart in the identified public LSSP artifacts. The public smoke uses a different code SHA and ENGINEERING_SMOKE_ONLY status, so it is not a provenance-identical final campaign file. The complete final matrix retains all 468 keys to preserve its scientific and validation identity. [The exact sorted key list](validation/public_smoke_overlap.json) and public-only validator allow independent rechecking.

Public GitHub manuscript tables already contain selected projections of pairwise reversals, ranking correlations, sample complexity and top-k overlap; no full 990-record telemetry-model table was found there. All 36 temporal-robustness numerical records are public in the [RQ5 table](https://github.com/SoroushVahidi/llm-serving-scheduler-robustness-benchmark/blob/main/paper/generated/table_data/rq5_temporal_robustness.json). Its unchanged canonical file is included for provenance and exact manuscript-generator input, not new numerical content. The manuscript already reports headline findings.

The 18,252 count is measured against identified public sources and exact matching keys. It is not a universal claim that no other copy exists. A bounded third-party search found no demonstrably equivalent result matrix; unindexed supplements and uninspected payloads remain uncertain. This release preserves all earlier public version, Git tag, DOI, and file identities.
