\paragraph{Data availability.} This study distinguishes four categories of
data, consistent with \S\ref{sec:artifact}. \textbf{Externally sourced
public traces} (BurstGPT, Azure 2024, Bailian/Qwen) are governed by their
original publishers' release terms and license status
(\S\ref{sec:provenance}; BurstGPT: CC-BY-4.0) and are not redistributed as
part of this project's release; readers should obtain them from their
original sources. \textbf{Derived benchmark manifests} (the frozen window
identities, provenance, and content hashes, \S\ref{sec:windows}),
\textbf{generated campaign results} (the paired policy outcome matrix
across windows, regions, and metrics, \S\ref{sec:results}), and
\textbf{analysis artifacts} (ranking-portability statistics, reversal
tables, and reproduction scripts) are publicly available at the Hugging
Face dataset repository
\url{https://huggingface.co/datasets/SoroushVahidi/llm-serving-scheduler-portability},
with frozen manifests and code additionally available at the GitHub
repository
\url{https://github.com/SoroushVahidi/llm-serving-scheduler-robustness-benchmark}.
An immutable snapshot of the code repository at the version reported here
is archived with a persistent identifier via Zenodo, DOI
\href{https://doi.org/10.5281/zenodo.22306798}{10.5281/zenodo.22306798}.
The Hugging Face release is an initial, dataset-card-scoped publication
(\S\ref{sec:artifact}); it does not yet include the exploded per-cell
campaign matrix or the raw per-cell RQ6 execution records, both of which
are candidates for a future dataset revision, and both of which are
represented in the current release by the canonical analysis outputs and
reduced RQ6 result sufficient to verify every number reported in this
manuscript.

\paragraph{Code availability.} The simulator, policy implementations, and
