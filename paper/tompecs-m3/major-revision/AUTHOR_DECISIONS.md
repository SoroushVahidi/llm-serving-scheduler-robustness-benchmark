# Author decisions before administrative finalization

These are proposed fields for human review, not signed declarations. Earlier user-verified dispositions are settled. The scientific verdict in the final report is distinct from permission to submit or a prediction of acceptance.

| Item | Required author decision / proposed prose |
|---|---|
| Authorship/contact | **[CONFIRM complete author list/order, affiliations at time of work, corresponding author, email and ORCID.]** Inherited front matter is not newly certified. |
| Contributions | **[CONFIRM each person's conceptualization, methodology, software, validation, analysis, data curation, visualization, writing, supervision/resources and funding roles.]** |
| Funding/support | “This work was supported by **[CONFIRM funders/awards and supported activities]**; computational/in-kind support: **[CONFIRM]**.” No absence or historical grant acknowledgment is assumed. |
| COI | **[CONFIRM financial/nonfinancial competing interests; use a no-conflict declaration only after verification.]** |
| Research-AI methods/history | “OpenAI Codex assisted manuscript revision, inspection of frozen code and saved records, development of read-only example analysis and independent-check implementations, display preparation, and validation/packaging. No new simulated requests or Monte Carlo studies were generated for this revision. **[CONFIRM complete earlier research-AI history, known tools/versions, affected methods/artifacts, human checking and responsible authors.]**” Place the completed statement in Methods. |
| Human responsibility | “**[CONFIRMED HUMAN AUTHORS]** reviewed and verified the methods, evidence, code, references and manuscript, and take responsibility for its contents.” This is proposed future approval text, not an assertion that review has happened. |
| Related manuscripts | **[APPROVE RELATED_MANUSCRIPTS.md, confirm actual submitted versions and stable identities/attachments where venue rules require them.]** Historical rejections/withdrawal need no reopening. |
| Availability/versioning | **[APPROVE external reviewer delivery, immutable version/archive plan, retention owner/duration and access procedure.]** The complete rc1 evidence remains local; the companion has the revised manuscript/support. No release or DOI has been created. |
| Rights/licenses/notices | **[APPROVE compilation, code and synthetic-data license scopes, source attribution/change notices, third-party rights and author-specific OA arrangements.]** Consumed source licenses are already verified. |
| Venue rules | **[OBTAIN current official ToMPECS format/anonymity/length/supplement/declaration rules before submission.]** HTTP 403 leaves them unverified; no invented cap. |
