## Artifact verification implementation

`verify_candidate.py` is read-only with respect to input evidence and writes explicit outputs. It verifies archive-manifest hashes, launch source fingerprints, every C01 result and journal against frozen analysis hashes, and all three payload hashes of every STAT integrity record. Portable adaptations of the PR17 checkers independently recompute terminal metrics and 1,440 chunked/decode terminal matches, all final STAT moment/bound summaries, classifications and stopping looks. Numeric discrepancy tolerances are asserted (1e-12); missing terminal files now fail immediately rather than being skipped.

The optional fixed sample adds independent replay of 24 journals and 200 existing study records in eight scenarios, including the original scenario-11/replicate-6628 arithmetic discrepancy. The original port/source/exact distinction is preserved. These are existing-data referees, not new simulated requests, Monte Carlo draws or rejection-vector claims for all 134,000 studies.

`validate.py --standalone` verifies the extracted manuscript without requiring `.git` or the historical consolidated dataset. It labels that preservation check `NOT_RUN_STANDALONE`; the author workspace separately performs it. Scripts resolve input roots from their location or explicit CLI arguments. Absolute paths inside frozen launch/provenance records are historical identities, not hidden dependencies of the saved-data workflow.
