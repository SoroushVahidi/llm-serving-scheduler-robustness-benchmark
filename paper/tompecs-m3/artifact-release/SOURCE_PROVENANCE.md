## Transformations and required notices

The frozen C01 manifest records all 120 source windows, valid-row start indices, seeds, source-file hashes and window-content hashes. `inputs/full-inputs.json` stores all 720 derived condition records (200 requests each). Readers can inspect/reproduce the executed inputs directly without reselecting the original dataset. Frozen loaders use timestamps and input/output token lengths, apply valid-row filtering and deterministic window selection, rebase arrivals, construct uniform priorities and synthetic output-derived deadlines, and jointly divide arrival gaps and deadline slack by the inherited factor. Token lengths remain unchanged. The historical prediction is seeded log-normal multiplicative noise around actual output length (relative-error parameter 0.20), and deadline slack is 20 times the linear prompt/predicted-output service proxy; these predictions and deadlines are not exposed to CM policies. Exact cost constants and rounding rules remain in `benchmark_synthesis.py`. The original 52,145,952-byte frozen window file and pilot input payload are additionally preserved under `evidence/input-lineage/`, alongside archived consolidated/pairwise support. `hash_ids` encode blocks in Alibaba but do not replace the direct length fields. The exact source and input definitions are in the candidate's pinned code and manifests.

These are research transformations, not provider-supplied deadlines or independent provider samples. The acquisition rename is distinct from those transformations. Saved study arrays in STAT01 are synthetic and use no serving-trace inputs; they have their own code/seed/identity provenance.

[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) identifies creators, source links, license texts, requested papers and modifications. For CC BY, retain supplied attribution/copyright/license/disclaimer information, link the license, identify changes and avoid suggesting endorsement; the license permits sharing/adaptation but does not grant unrelated privacy/trademark rights. Apache 2.0 additionally requires a copy of the license, retained relevant source notices, and prominent notices on modified files. No separate upstream Alibaba NOTICE was present at the pinned commit. No license is inferred merely from public visibility.

Frozen machine inputs must not be rewritten to add headers. Candidate packaging places a prominent `.NOTICE.txt` companion beside each derived JSON/input record and CSV, with a shared file-scope notice; these companions are new packaging files, not changes to frozen bytes. **Before external release the author must approve this packaging form and the candidate's own code/data/manuscript license scopes.** The scientific source identity and explicit license coverage are verified; release approval, attribution packaging acceptance and author-owned rights remain distinct decisions, not an unresolved Azure rename.
