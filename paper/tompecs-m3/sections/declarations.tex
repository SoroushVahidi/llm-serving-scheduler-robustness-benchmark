\section*{Code and Data Availability}
The manuscript's reproduction materials include source, figure and table
scripts, frozen analysis summaries, input fingerprints, and supplementary
CSVs containing all 5,760 C01 cells and 7,200 STAT01 endpoint summaries.
A compact supplementary review package provides these materials and a
manifest linking them to a separately preserved full evidence package,
which contains the pinned execution code and complete saved campaign
records. Regenerating displays from those
records is distinct from acquiring upstream inputs and replicating the
experiments. The packages are prepared for confidential reviewer delivery;
no public release, archival DOI, or hosted reviewer-access URL is asserted.
Original third-party raw workload
traces are excluded from the packages and must be acquired from
the attributed upstream sources. The intended license scopes are MIT for
original code and CC BY 4.0 for eligible original research data and results,
with upstream terms retained.
